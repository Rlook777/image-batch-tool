# 功能 A:批量抓取網站圖片

> 狀態:⏸️ **暫緩**(2026-08-13 使用者決定,先開發馬賽克與浮水印)
> 相關文件:[總覽 requirements.md](../requirements.md)
> ⚠️ 本功能為整個項目風險最高、最不穩定的部分,請先讀第 6 節難易度評估

## 1. 功能描述

輸入網址,自動抓取該頁面上的圖片,以縮圖牆呈現供勾選,再送入後續處理(馬賽克 / 浮水印)或直接下載。

## 2. 使用流程

```
貼上網址(支援一次貼多個,一行一個)
    ↓
後端爬取頁面 → 解析出圖片 URL 清單
    ↓
後端代理下載圖片 → 回傳前端
    ↓
縮圖牆顯示:全選 / 反選 / 逐張勾選 + 過濾(尺寸、格式)
    ↓
確認選取 → 進入處理流程或直接下載
```

## 3. 功能細節

### 圖片來源解析
- `<img src>`、`<img srcset>`(取最大解析度)、`<picture>` / `<source>`
- CSS `background-image`(第二階段再做)
- 相對路徑轉絕對路徑、去重

### 過濾條件
- 最小寬/高(預設 200px,排除 icon、追蹤像素)
- 格式:jpg / png / webp / gif

### 縮圖牆 UI
- Grid 排列,顯示縮圖、原始尺寸、檔案大小、格式
- 全選 / 全不選 / 反選、單張點擊放大

## 4. 技術實作

### 抓取策略
目標網站(見第 6 節)全是重度 JS 動態網站,**純 HTTP 抓取無效**,直接上 Playwright:
1. Playwright 開 headless 瀏覽器載入頁面
2. 滾動觸發 lazy-load,等網路閒置
3. 收集 DOM 中所有圖片 URL(含動態插入的)

### CORS 與代理
瀏覽器 CORS 限制使前端無法讀取跨域圖片像素(Canvas 會被 taint),
因此**所有圖片下載走後端代理**,前端拿到同源資源。

## 5. 安全性(公網部署必做)

後端代理「下載任意 URL」是 **SSRF 高風險點**:

| # | 防護 | 說明 |
|---|------|------|
| 1 | 封鎖內網位址 | DNS 解析後拒絕 127.0.0.0/8、10/8、172.16/12、192.168/16、169.254.169.254(雲端 metadata);必須在 **DNS 解析後** 檢查,防 DNS rebinding |
| 2 | 協定白名單 | 只允許 http / https |
| 3 | 大小與逾時 | 單張圖上限 20MB、逾時 10 秒,streaming 邊下載邊檢查 |
| 4 | Content-Type 驗證 | 只代理 `image/*` |
| 5 | Redirect 限制 | 跟隨上限 3 次,每跳重新做內網檢查 |
| 6 | Rate limit | 公網必加,避免被當免費爬蟲/代理濫用 |

## 6. 難易度與風險評估(重要,部署前必讀)

指定目標:**Pornhub、Instagram、Facebook**。三者都是業界最難抓的網站類型。

### 技術難度:高,且會持續衰退
- **反爬蟲**:行為偵測、指紋辨識、rate limit、IP 封鎖。Playwright 也會被偵測到,需要反偵測手段(stealth plugin、住宅代理 IP),而且對方會持續更新對策,你的爬蟲**會週期性壞掉**,需要不斷維護
- **登入牆**:IG / FB 大部分內容需登入才看得到。若要抓,需帶 cookie/session,涉及帳號被封風險
- **不穩定**:今天能抓不代表明天能抓,這是抓圖功能的本質問題,無法根治

### 法律 / 合規風險(公網部署放大這些風險)
- 抓取這些網站違反其 **服務條款(ToS)**
- 圖片有**著作權**;批量下載 + 加工 + 再散布可能構成侵權
- Pornhub 為**成人內容**:公網部署需年齡驗證、內容分級,且多數雲端服務商(AWS/GCP/Vercel 等)的使用政策禁止託管成人內容相關服務
- 若處理到含真實人物的照片,加馬賽克/浮水印後散布可能涉及**肖像權、隱私、甚至加工不當內容**的法律問題

### 我的建議
1. **抓圖功能與部署範圍分開看**:圖片處理(馬賽克/浮水印/下載)是正當且低風險的,可以正常做、正常部署
2. **抓圖功能建議「僅本機自用」**,不要開放給公網不特定人使用——公網開放一個能抓任意站(含成人站)的下載代理,法律與濫用風險過高
3. 若堅持公網含抓圖:務必加登入授權(限自己或白名單使用者)、完整 rate limit、且自行確認部署平台的內容政策
4. 抓圖穩定性請預期為「盡力而為」,不保證長期可用

## 7. 待確認問題

## 8. 驗收標準

- [ ] 貼上目標頁面網址,能顯示縮圖牆(盡力而為,受對方反爬影響)
- [ ] 過濾條件即時生效
- [ ] 對內網 URL(如 `http://192.168.1.1`、`http://169.254.169.254`)請求被後端拒絕
- [ ] 非圖片資源不會被代理回傳
