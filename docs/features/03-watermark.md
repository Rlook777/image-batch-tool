# 功能 C:批量上浮水印(自訂圖片)

> 狀態:草稿,待確認
> 相關文件:[總覽 requirements.md](../requirements.md)
> 建議作為第一個開發的功能:純前端、無外部依賴、最快看到成果

## 1. 功能描述

上傳自己的圖片(logo、簽名檔等,建議 PNG 透明背景)作為浮水印,批量疊加到選中的圖片上,位置/大小/透明度可調,支援平鋪防盜。

## 2. 使用流程

```
上傳浮水印圖片(PNG 透明背景最佳)
    ↓
選好要處理的目標圖片
    ↓
調參數:位置、大小、透明度、(選配)平鋪
    ↓
單張即時預覽
    ↓
批量套用(進度條)→ 進入下載
```

## 3. 功能細節

### 可調參數
| 參數 | 範圍 / 選項 | 說明 |
|------|-------------|------|
| 位置 | 九宮格(左上/中上/右上/…/正中/…/右下) | 快速定位 |
| 位置微調 | X / Y 偏移(px 或 %) | 在九宮格基礎上細調 |
| 大小 | 相對原圖寬度的 5% ~ 100% | 按比例縮放,浮水印隨原圖大小自適應 |
| 透明度 | 0 ~ 100% | 滑桿即時預覽 |
| 平鋪模式 | 開 / 關 | 開啟則整張重複鋪滿,防裁切盜圖 |
| 平鋪間距 / 旋轉角度 | (平鋪模式下) | 選配,傾斜鋪更難去除 |

### 自適應定位重點
不同尺寸的目標圖片,浮水印用**相對比例**定位與縮放,
確保大圖小圖上浮水印視覺比例一致(不會小圖上蓋滿、大圖上小到看不見)。

## 4. 技術實作(Canvas)

### 疊加
1. 先 `drawImage` 畫原圖
2. 設 `globalAlpha` = 浮水印透明度
3. 依位置/大小計算浮水印目標矩形,`drawImage` 畫浮水印
4. 平鋪模式:用兩層迴圈重複繪製,或用 `createPattern`

### 效能
- 浮水印圖只解碼一次,重複用於所有目標圖
- 100 張以內用 Canvas 逐張處理即可,大批量可考慮 Web Worker 避免卡 UI

## 5. 待確認問題

1. 需要「多個浮水印」同時疊加嗎?(例如左上 logo + 右下簽名)目前規劃**單一浮水印**
2. 需要文字浮水印嗎?(打字產生浮水印)目前規劃**只支援圖片浮水印**
3. 平鋪模式要做進第一版嗎?

- [ ] 不同尺寸目標圖,浮水印相對比例一致
- [ ] 平鋪模式鋪滿無縫(若做)
