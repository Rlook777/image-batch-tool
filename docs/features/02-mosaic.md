# 功能 B:批量上馬賽克(整張 + 框選,透明度可調)

> 狀態:草稿,待確認
> 相關文件:[總覽 requirements.md](../requirements.md)

## 1. 功能描述

對選中的圖片批量套用馬賽克。支援**兩種模式**(依你的確認,兩種都做):
- **模式一:整張圖馬賽克** — 整張套用
- **模式二:框選區域馬賽克** — 手動拖框選特定區域(遮臉、遮車牌、遮敏感部位),可框多個區域

## 2. 使用流程

```
選好要處理的圖片
    ↓
選模式:整張 / 框選
    ↓
[框選模式] 在預覽圖上拖曳框出區域(可多框、可刪除)
    ↓
調參數:馬賽克強度(格子大小)+ 透明度
    ↓
單張即時預覽
    ↓
批量套用(進度條)→ 進入下載或繼續加浮水印
```

## 3. 功能細節

### 可調參數
| 參數 | 範圍 | 說明 |
|------|------|------|
| 效果類型 | 像素馬賽克 / 毛玻璃 | 2026-08-14 新增毛玻璃;架構預留擴充(模糊/噪點/純色) |
| 強度 | 5 ~ 50 px | 像素馬賽克=格子大小;毛玻璃=模糊半徑 |
| 透明度 | 0 ~ 100% | 0=看不到效果(原圖),100=完全遮蓋;滑桿即時預覽 |
| 模式 | 整張 / 框選 | 兩種效果共用範圍模式與框選邏輯 |

### 毛玻璃效果組成
高斯模糊(Canvas 原生 `ctx.filter: blur`)+ 細噪點層 + 輕微提亮,近似 iOS 毛玻璃質感。

**隱私提醒(UI 需標示)**:模糊類效果理論上可能被 AI 部分還原,
遮擋敏感資訊(人臉、車牌、文字)建議用高強度像素馬賽克。
瀏覽器相容:`ctx.filter` 需 Safari 18+/Chrome/Firefox 近代版本,不做舊版 fallback。

### 框選模式細節
- 在預覽圖上滑鼠拖曳畫矩形框
- 可畫多個框(例如同時遮兩張臉)
- 每個框可點選刪除、可拖曳調整
- **座標換算**:預覽圖是縮放後的,框選座標需按比例換算回原圖實際像素,確保輸出馬賽克位置精準
- 批量套用時,同一組框套用到所有選中圖(注意:不同尺寸圖片用相對比例定位)

## 4. 技術實作(Canvas)

### 馬賽克演算法
標準做法:**縮小再放大**
1. 把(整張或框選區域)用 Canvas 縮小到 `1/格子大小`
2. 關閉平滑(`imageSmoothingEnabled = false`)再放大回原尺寸 → 產生格子效果

### 透明度實作
馬賽克層與原圖層疊合,用 `globalAlpha` 控制馬賽克層透明度:
- `輸出 = 原圖 × (1 - alpha) + 馬賽克 × alpha`
- alpha=0 → 完全原圖;alpha=1 → 完全馬賽克

### 框選區域處理
只對框內像素做上述處理,框外保持原樣。

## 6. 驗收標準

- [ ] 整張模式:調強度/透明度即時預覽,批量套用結果一致
- [ ] 框選模式:框選區域精準對應原圖像素(不同尺寸圖片驗證)
- [ ] 透明度 0% 時輸出等於原圖,100% 時完全馬賽克
- [ ] 100 張批量套用不崩潰,有進度顯示
