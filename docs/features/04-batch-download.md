# 功能 D:批量下載

> 狀態:草稿,待確認
> 相關文件:[總覽 requirements.md](../requirements.md)

## 1. 功能描述

處理完成後,把所有圖片一鍵打包成 ZIP 下載,檔名規則可設定。

## 2. 功能細節

### 檔名規則
- 保留原檔名
- 加前綴 / 後綴(例如 `wm_原檔名`、`原檔名_processed`)
- 流水號(`image_001.jpg`、`image_002.jpg` …)
- 檔名衝突自動加序號避免覆蓋

### 輸出格式
| 選項 | 說明 |
|------|------|
| 維持原格式 | jpg 輸出 jpg,png 輸出 png |
| 統一格式 | 全部轉 jpg(檔案小)或 png(無損) |
| JPG 品質 | 輸出 jpg 時可調品質 0.6 ~ 1.0 |

## 3. 技術實作

- **JSZip** 在前端打包:處理後的 Canvas 用 `canvas.toBlob()` 轉檔,加入 ZIP
- 大批量用 `generateAsync` + 進度 callback 顯示打包進度
- 產生的 ZIP 用 blob URL 觸發下載

### 注意
- 100 張以內前端打包沒問題;若未來單批數量很大(數百 MB),瀏覽器記憶體會吃緊,屆時再考慮改後端串流打包
- 下載完釋放 blob URL,避免記憶體洩漏
