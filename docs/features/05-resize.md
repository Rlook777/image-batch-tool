# 功能 E:輸出尺寸調整(統一寬度)

> 狀態:✅ 第一版(2026-08-14)
> 相關文件:[總覽 requirements.md](../requirements.md)

## 1. 功能描述

批量輸出時把所有圖片縮放到**統一寬度**,高度依原圖比例等比跟隨(不變形)。

使用者決策(2026-08-14):Layout 功能只做 Resize,策略為統一寬度。
裁切/旋轉/補邊列為未來擴充。

## 2. 功能細節

- 在「輸出與下載」面板:啟用開關 + 目標寬度輸入(px,預設 1080,範圍 16~8192)
- 小於目標寬度的圖**會被放大**(統一寬度語意);放大會失真,UI 註明
- 效果套用順序:**先縮放 → 再上馬賽克/浮水印**,
  馬賽克強度(px)與浮水印比例都以輸出解析度為準,預覽與輸出一致

## 3. 技術實作

- `renderProcessed` 增加 `targetWidth` 參數:先把原圖縮放繪製到中介 canvas,
  之後的馬賽克取樣與浮水印都以該 canvas 為基底
- 預覽端的 `blockScale` 改為 `預覽圖寬 / 輸出寬`(原本是 `預覽圖寬 / 原圖寬`)

## 4. 驗收標準

- [ ] 啟用統一寬度 500,輸出 ZIP 內所有圖寬度皆為 500、比例不變形
- [ ] 停用時輸出維持原尺寸
- [ ] 馬賽克/浮水印在縮放後的圖上位置與強度正確
