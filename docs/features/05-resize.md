# 功能 E:Layout 尺寸調整

> 狀態:✅ 第二版(2026-08-14 依使用者反饋重構)
> 相關文件:[總覽 requirements.md](../requirements.md)

## 1. 功能描述

Figma 式的尺寸面板:輸入自訂 W/H,可鎖定長寬比,
套用範圍可選**單一圖片(目前預覽的那張)**或**批量(所有勾選的圖)**。

版本歷程:
- v1(統一寬度,全域設定)→ 使用者反饋要自訂大小 + 單張/批量二選一 → v2 重構為每張圖獨立的尺寸覆寫

## 2. 功能細節

- 獨立「尺寸 Layout」面板,顯示目前預覽圖的原始尺寸
- W / H 數字輸入(px,16~8192)
- 🔒 鎖定長寬比(預設開):改 W 自動算 H(反之亦然);解鎖可自由變形
- 套用範圍:單張(目前預覽)/ 批量(已勾選)
- 「還原原始尺寸」按鈕,同樣分單張/批量
- 縮圖牆顯示覆寫後的輸出尺寸(`原尺寸 → 新尺寸`)
- 只調尺寸不開馬賽克/浮水印也能下載(純 resize 用途)

## 3. 技術實作

- 尺寸覆寫存在每張圖上:`targetW` / `targetH`(`targetH = null` 表示等比,由 `targetW` 推算)
- `renderProcessed` 接受 `targetW/targetH`:先縮放到目標尺寸再套效果
- 預覽會真實反映目標比例(含變形),效果強度以輸出解析度為準

## 4. 未來擴充(未做)

- 裁切 Crop(固定比例置中裁)、旋轉/翻轉、補邊 Pad

## 5. 驗收標準

- [ ] 單張套用 W/H,只有該圖輸出尺寸改變
- [ ] 批量套用,所有勾選圖改變;鎖定比例時各自等比
- [ ] 解鎖後自由 W×H,輸出正確變形
- [ ] 還原按鈕清除覆寫
- [ ] 不開任何效果、只改尺寸也能下載
